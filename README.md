# Aceleracionismo Cosmista

Um projeto Next.js 15 com Three.js, Framer Motion e Tailwind CSS.

## Stack Tecnológico

- **Next.js 15.1.0** - Framework React
- **React 19** - Biblioteca UI
- **Three.js** - Renderização 3D
- **@react-three/fiber** - Integração React + Three.js
- **@react-three/drei** - Utilitários para Three.js
- **Framer Motion** - Animações
- **Tailwind CSS** - Estilização
- **TypeScript** - Type safety

## Como Rodar Localmente

```bash
# Instalar dependências
npm install

# Rodar em desenvolvimento
npm run dev

# Build para produção
npm run build

# Iniciar servidor de produção
npm run start
```

Acesse [http://localhost:3000](http://localhost:3000)

## Deploy

Este projeto está configurado para ser deployado facilmente no [Vercel](https://vercel.com).

1. Faça push para GitHub
2. Conecte seu repositório no Vercel
3. Clique em Deploy

## Estrutura do Projeto

```
.

├── next.config.js   # Configuração Next.js

```
